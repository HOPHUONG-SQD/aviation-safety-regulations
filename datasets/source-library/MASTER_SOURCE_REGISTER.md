## Status Codes

| Code | Meaning |
|---|---|
| VERIFIED — CURRENT | Official source, revision and effective status confirmed |
| VERIFIED | Source identity confirmed; currency review may still be required |
| VERIFICATION REQUIRED | One or more critical source attributes remain unconfirmed |
| SUPERSEDED | Replaced by a later document |
| NOT LOCATED | Official source has not been located |
| REFERENCE ONLY | Useful information but not a controlling regulatory source |

## Source Priority

| Priority | Source type |
|---|---|
| P0 | Official law, regulation, authority decision, certificate or approval record |
| P1 | Official AMC, GM, advisory circular, user guide or authority instruction |
| P2 | Recognised industry or technical standard |
| P3 | Peer-reviewed research or professional analysis |
| P4 | Unofficial summary or general reference material |

## Verification Rules

1. Verify sources using the issuing authority or official legislation portal.
2. Do not determine currency from a search result or document title alone.
3. Record the exact revision, amendment and effective date.
4. Read the applicable provision in context.
5. Separate mandatory requirements from guidance.
6. Separate approval status from approved scope.
7. Do not convert `VERIFICATION REQUIRED` into compliant or non-compliant.
8. Record conflicting or inaccessible sources without selecting one silently.
9. Update the verification date whenever a source is substantively checked.
10. Preserve superseded records for traceability.
