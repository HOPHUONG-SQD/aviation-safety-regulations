# Regulatory Source Verification Log

## 1. Purpose

This log records each regulatory-source verification performed for the Aviation Safety Regulations project.

It provides traceability for:

- Source identification
- Official-source access
- Revision and effective-date checks
- Applicability decisions
- Status changes
- Conflicting evidence
- Open verification actions
- Independent review

## 2. Instructions

Create one log entry for each substantive verification activity.

A substantive verification includes:

- Verifying a new regulatory source
- Confirming a revision or amendment
- Checking an effective date
- Reassessing applicability
- Identifying a superseded source
- Reviewing approval status or scope
- Resolving conflicting evidence
- Changing a controlled source status

Do not create a new entry merely because a link was opened.
