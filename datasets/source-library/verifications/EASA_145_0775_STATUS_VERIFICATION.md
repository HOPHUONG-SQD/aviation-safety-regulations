## 4. Status and Scope Boundary

This Status Dataset supports confirmation of:

- Approval number
- Organisation name
- Country
- Inclusion in EASA's valid Foreign Part-145 dataset

It does not independently confirm:

- Approved locations
- Detailed maintenance levels
- Current Certificate revision
- Current Terms of Approval revision
- Current MOE revision
- Detailed C07 capability
- Organisation compliance

Scope details must be reconciled with the Certificate, Terms of Approval, approved MOE and Capability List.
